# ziptype

Zip and reshape type text streams with deterministic transforms.

**Site:** https://theworker02.github.io/ziptype/

## Install / run

```bash
git clone https://github.com/theworker02/ziptype.git
cd ziptype
node src/cli.js
node --test
```
